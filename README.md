## 🏆 Featured Projects

### 1. Scrolla 📱
An Android app that turns how far you scroll into real-world distance, then ranks friends on a reverse leaderboard — lowest wins.
* **Native Android Stack:** Built with **Kotlin** and **Jetpack Compose** (Material 3), backed by **Room** for local persistence and **Firebase Auth + Firestore** for cross-device sync.
* **Pixel-to-Distance Engine:** An **AccessibilityService** tracks per-view scroll deltas system-wide and converts raw pixels into cm/km, with a foreground service and OEM battery-whitelist handling so tracking survives aggressive power management.
* **Inverted Social Layer:** Multi-group leaderboards, personal records, weekly recaps and per-app breakdowns — gamification turned upside down so the lowest scroller takes the top spot.

### 2. MayDay 🆘
An offline-first disaster response platform for rural areas where internet, cellular networks and power have failed completely.
* **Mesh-First Architecture:** Built with **Flutter** and **Dart**, relaying location-tagged SOS alerts, hazard reports and resource pins phone-to-phone over Bluetooth and Wi-Fi Direct — no server, no internet path anywhere in the design.
* **Corroboration Trust Engine:** Claims gain confidence only when physically distinct devices independently confirm them; relaying deliberately counts as no evidence, volunteers can ground-confirm on site, and life-critical SOS claims never decay or get evicted.
* **Zero-Network Identity:** Device keypairs in hardware-backed storage sign every claim, campaign-issued volunteer credentials establish authority, and web-of-trust vouching onboards new responders mid-disaster — all verifiable with no server. Built with a three-person team at `monish1929/MayDay`.

### 3. FrayFuse 🔗
A supply-chain finance engine that identifies which suppliers are about to run out of cash, cannot be replaced, and how much money would stabilise each one.
* **Deterministic Propagation, No ML:** A four-stage **Python** + **NetworkX** model — stress read from published MSMED and ageing disclosures, contagion propagated buyer→supplier against goods flow, criticality normalised within tier, ranked by `fragility × criticality`.
* **Funding Decisions, Not Dashboards:** Counterfactual interventions and a budget allocator convert risk into rupees — funding a single sole-source supplier with ₹2.04 cr drains the anchor's supply risk from ₹848.96 cr to ₹308.36 cr.
* **Full-Stack & Verified:** **FastAPI** backend with a **React 19 + TypeScript + Vite** force-directed console, covered by 169 Python and 26 web tests with determinism verified across scoring, mock generation and the CSV transform.

### 5. Respira-AI 🫁
An advanced Clinical Decision Support System (CDSS) engineered for high-precision respiratory diagnosis.
* **Full-Stack Architecture:** Built with **Next.js 16** (Frontend) and **FastAPI** (Backend) for real-time clinical responsiveness.
* **Hybrid Clinical Engine:** Powered by **XGBoost** to normalize physiological data against patient demographics (Age/Gender/Height).
* **Probabilistic Risk:** Delivers granular "Confidence Scores" (0-100%) rather than simple binary classifications, mimicking expert medical reasoning.

### 6. Voltaic 🚗
An advanced EV Journey Intelligence Platform engineered to eliminate range anxiety for Indian EV owners using physics-backed route predictions.
* **Full-Stack Platform:** Built with **Next.js 16**, **TypeScript**, and **Supabase (PostgreSQL + PostGIS)**, integrated with **Mapbox** for routing and geocoding.
* **Deterministic Physics Engine:** Models every 5km route segment using a 4-force Newtonian model — aerodynamic drag, rolling resistance, gradient, and thermal penalty — with zero ML or GPU inference.
* **Recursive Auto-Rescue & Trust Score™:** An A*-inspired algorithm auto-injects charging stops when battery SoC drops below 25%, paired with a proprietary 0–100% confidence score explaining prediction reliability.

### 7. SkillSphere 🌐
A hyperlocal, AI-powered freelance marketplace eliminating friction between clients and skilled professionals.
* **Full-Stack Monorepo:** Built with **Next.js 16**, **React 19**, and **TypeScript**, using a unified npm workspace architecture with Supabase, Clerk, and Razorpay.
* **Semantic AI Matching:** Powered by HuggingFace's **all-MiniLM-L6-v2** sentence-transformer to compute cosine similarity between gigs and freelancer profiles, returning ranked top-5 matches.
* **Escrow & Real-Time Collaboration:** Razorpay-backed milestone escrow with dispute resolution, paired with Socket.IO chat, file attachments, and live notifications.
